RavestickBoard for CoolLED1248 | Update auf v0.1.1
================================================

Dies ist ein kompletter Dateistand fuer dein bestehendes privates Git-Repository.
Die bisher getestete v0.1.0 bleibt unter firmware/CoolLED1248_Web_v0_1_0.ino erhalten.

1. Entpacke dieses ZIP in einen neuen temporären Ordner.
2. Kopiere DEN INHALT des entpackten Ordners in den bestehenden lokalen
   Git-Repository-Ordner RavestickBoard-for-CoolLED1248. Windows darf gleichnamige
   README.md-, CHANGELOG.md- und docs/-Dateien überschreiben.
   Den versteckten .git-Ordner im Repository NICHT löschen oder überschreiben.
3. Öffne firmware/RavestickBoard_v0_1_1.ino mit der Arduino IDE.
   Falls Arduino einen gleichnamigen Unterordner anlegen möchte: bestätigen.
4. Board: ESP32C3 Dev Module; Port: der erkannte COM-Port;
   USB CDC On Boot: Enabled; Partition Scheme: No OTA (2MB APP/2MB SPIFFS).
5. Kompilieren und aufspielen. Wenn ein Kompilierfehler erscheint, erst dessen
   genauen Wortlaut sichern. Nicht die funktionierende v0.1.0 löschen.
6. Mit dem bisherigen WLAN CoolLED1248 verbinden, http://192.168.4.1 aufrufen.
   Im Kopf muss RavestickBoard v0.1.1 stehen. Diagnose unten aufklappen.
7. TESTPLAN.md, bzw. docs/TESTPLAN.md beachten. Nach erfolgreichem realen Test
   die Testergebnisse im CHANGELOG und THEMENSPEICHER festhalten.
8. GitHub Desktop: geänderte Dateien prüfen, Commit erstellen:
   v0.1.1: Diagnostics, logging and project rebranding
   Danach Push origin in das PRIVATE Repository.

Geändert:
- Sichtbarer Projektname und Version v0.1.1 im Header
- Diagnoseanzeige + TXT-Download für Fehleranalyse
- RAM-Ringpuffer für 56 Ereignisse, Speicher- und BLE-Metriken
- Mobilansicht: 7 Farben in einer Zeile, 100 % ohne Umbruch, mehr Platz am Seitenende
- Dokumentationspaket synchronisiert

NICHT GEÄNDERT:
- WLAN: CoolLED1248 (Passwort im Firmware-Quellcode)
- Keine OTA-Updates, weiterhin nur USB
- Text wird nur auf Knopfdruck gesendet
- 5×7 Engschrift ohne echte Kleinbuchstaben
- Automatischer Wechsel auf Lauftext bei mehr als 64 Pixeln
- Noch keine pixelgenaue 64×16-Lauftext-Vorschau

WICHTIG: Quellcode ist ein TESTKANDIDAT; kein echter ESP32-Core-Compile
oder Test auf der LED-Tafel wurde innerhalb dieser Entwicklungsumgebung gemacht.
TXT-Ereignislog ist nur im RAM und nach Reset/Stromausfall verloren.
TXT-Export moeglichst VOR einem Reset ausführen.
